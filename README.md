# আদেশ-নিষেধের আয়াত — Android অ্যাপ

কুরআনের ৫১৫টি আদেশ ও নিষেধমূলক আয়াত, ২১টি বিষয়ে সাজানো। তেলাওয়াত করেছেন শায়খ মিশারী রাশিদ আল-আফাসি,
অডিও আসে everyayah.com থেকে (`Alafasy_64kbps`)।

## ফিচার
- **একের পর এক প্লে:** কোনো আয়াতে চাপ দিলে সেখান থেকে শুরু হয়। একটি আয়াত শেষ হলে নিজে থেকেই পরেরটা বাজে।
- **রিপিট মোড (১.১):** ১ বার / ৫ বার / একটি আয়াত বারবার (Repeat One)। প্লেয়ারের চিপ চাপলে বা সেটিংস থেকে বদলানো যায়।
- **আরবি ক্বারী (১.২):** মিশারী রাশিদ আল-আফাসি / আব্দুল বাসিত আব্দুস সামাদ।
- **অনুবাদের অডিও (১.২):** বাংলা (প্রদীপ, পুরুষ কণ্ঠ) / বাংলা (নবনীতা, নারী কণ্ঠ) / উর্দু (শামশাদ আলী খান)।
  প্রতিটি আয়াতে কী বাজবে: শুধু আরবি / আরবি তারপর অনুবাদ / শুধু অনুবাদ।
- **বাংলা অনুবাদের অডিও:** `docs/audio/bn_pradeep/` আর `docs/audio/bn_nabanita/` (jsDelivr CDN দিয়ে পরিবেশিত)।
  `tools/gen_bn_audio.py` দিয়ে তৈরি (Microsoft নিউরাল ভয়েস)। কোনো শব্দের উচ্চারণ ভুল হলে স্ক্রিপ্টের
  `PRONUNCIATION_FIXES` তালিকায় যোগ করে সেই ফাইলগুলো মুছে আবার চালান।
- **বাংলা অনুবাদ দেখানো (১.১):** সেটিংসে চালু/বন্ধ করা যায়।
- **একবারই ডাউনলোড:** প্রথমবার বাজানোর সময় অডিও অ্যাপের নিজস্ব স্টোরেজে (`filesDir/audio`) সেভ হয়।
  পরেরবার ইন্টারনেট ছাড়াই বাজে। পরের আয়াতটি আগে থেকেই ডাউনলোড হয়ে থাকে, তাই মাঝে বিরতি হয় না।
- **সব অফলাইনে সেভ:** একবারে সব আয়াত ডাউনলোড করার বাটন (আবার চাপলে থেমে যায়)।
- **বিষয়ভিত্তিক ফিল্টার:** সালাত, যাকাত, পরিবার, লেনদেন ইত্যাদি ২১টি বিষয়।
- আরবি টেক্সট Amiri ফন্টে, বাংলা Hind Siliguri ফন্টে (দুটোই OFL লাইসেন্স)।

## APK বানানো
**GitHub Actions দিয়ে:** কোড `main` ব্রাঞ্চে push করলেই `.github/workflows/build-apk.yml` চালু হয়।
Actions ট্যাবে গিয়ে সর্বশেষ রান খুলুন, তারপর নিচে **adesh-ayat-apk** আর্টিফ্যাক্ট ডাউনলোড করুন।

**Android Studio দিয়ে:** ফোল্ডারটি Open করুন, Gradle sync শেষ হলে `Build > Build APK(s)` চাপুন।
অথবা টার্মিনালে লিখুন: `./gradlew assembleRelease`

রিলিজ APK এখন debug key দিয়ে সাইন হয়, তাই সরাসরি ফোনে ইনস্টল করা যায়।
Play Store-এ দেওয়ার আগে নিজের keystore দিয়ে সাইন করুন।
